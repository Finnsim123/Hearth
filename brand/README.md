# Hearth brand

**Official mark: Ember** (`logo.svg`) — house outline in `currentColor`,
ember dot fixed at `#F59E0B`. The outline adapts to theme; the ember never
changes color (it's the brand constant).

Files:
- `logo.svg` — canonical mark (square, 32 viewBox)
- `logo-ember.svg` — same file, kept under its concept name
- `explorations/` — rejected concepts (monogram, glow, roofline), kept for reference

Usage rules (see also docs/DESIGN.md §5):
- Wordmark: "hearth" lowercase, Inter 600, −0.02em, in `--text`, mark to the left
- Clear space: ½ mark height on all sides
- Minimum size 16px; at 16px drop the wordmark, mark only
- Favicon / HA brand icon: mark on transparent — outline `#111827` for light
  contexts, `#E7EAF0` for dark, ember dot always `#F59E0B`
- Never: recolor the ember, add gradients/shadows, rotate, or put the mark
  in a colored container darker than `--surface`
